# Lista de Problemas Ativos

Problemas conhecidos do projeto. IDs `#NNN` são estáveis e podem receber prefixo `[aceito-arquivado]`.

## Convenção

```
## #NNN — <título curto>
- severidade: alta | média | baixa
- classificação: consciente | (omitida quando acidental)
- detectado em: YYYY-MM-DD por @<handle>
- estado: ativo | em-investigação | aguardando-ADR
- referências: ADR-NNNN, .rime/registro/sessoes/<arquivo>.md, #issue
```

Problemas resolvidos migram para `passivos.md`.
